# Internacionalización (D2)

Marea Baja se publica en **español de Costa Rica (`es-CR`, predeterminado)** e **inglés (`en`)** desde la primera versión.

## Reglas

1. **Ningún texto de interfaz escrito en los componentes.** Todo texto visible o accesible (incluidos `aria-label`, `title`, `alt` y `placeholder`) sale de los archivos de mensajes. Lo hace cumplir la regla de ESLint `marea-baja/no-literal-ui-text` (`tools/eslint/no-literal-ui-text.js`).
2. **Las dos lenguas tienen las mismas claves y las mismas variables `{{…}}`.** Lo comprueba `apps/web/app/i18n/messages.test.ts`, que corre en CI.
3. **El idioma sale de la URL:** `es-CR` sin prefijo y `en` con `/en`. Lo resuelve `app/i18n/locale.ts`. No hay detección automática por navegador ni por IP (§4.2).
4. **Nombres originales de los platos:** no se traducen ("Tiradito nikkei", "Ceviche clásico") y se marcan con `translate="no"`. Sí se traducen las descripciones, las categorías y las opciones.
5. **Formatos con `Intl`:** precios con `formatMoney` (`@marea-baja/shared`) y fechas con `Intl.DateTimeFormat`. La moneda la define el negocio, no el idioma: en inglés también se ve "₡8,900".

## Dónde está cada cosa

| Qué | Dónde |
|---|---|
| Lista de idiomas y predeterminado | `packages/shared/src/i18n/locales.ts` |
| Mensajes de la web | `apps/web/app/i18n/locales/<idioma>/<espacio>.json` (`common`, `design`, …) |
| Configuración de i18next | `apps/web/app/i18n/config.ts` |
| Tipado de claves | `apps/web/app/i18n/i18next.d.ts` (una clave inexistente es un error de TypeScript) |
| Hook para componentes | `useT('espacio')` en `apps/web/app/i18n/use-locale.ts` |
| Segmentos de URL traducidos | `SEGMENTS` en `apps/web/app/i18n/locale.ts` (en M4 se agregan `carta → menu`, etc.) |

## Cómo agregar un texto

1. Agregá la clave en `es-CR/<espacio>.json` y en `en/<espacio>.json`, con las mismas variables.
2. En el componente: `const { t } = useT('<espacio>');` y luego `{t('mi.clave')}`.
3. Plurales: claves `_one` / `_other` y `t('clave', { count })`.
4. `npm run check` valida el lint, los tipos y la paridad de claves.

## Convenciones de redacción

- Español rioplatense neutro con voseo ("Revisá", "Elegí"), como en el sistema de diseño aprobado.
- En inglés se usan comillas y apóstrofos tipográficos (’) y sentence case.
- Puntos suspensivos con un solo carácter (…).
- Espacio no separable entre número y unidad ("24 px").
